## Overview

This repository contains the source for **[namth.id.vn](https://namth.id.vn)**, the personal portfolio of Nam Hoai. The site presents selected projects, technical experience, and contact information through a fast, responsive interface with a distinctive dark and neon visual identity.

## Highlights

- Dedicated Home, About, Projects, Experience, and Contact sections.
- Vietnamese and English content.
- Dark and light theme support.
- WebGL-powered visual background.
- Custom cursor, preloader, and smooth interactive effects.
- Responsive layout for desktop, tablet, and mobile.
- SEO-friendly metadata and social sharing information.
- Custom domain deployment through GitHub Pages.

## Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Semantic page structure |
| CSS3 | Responsive layout, themes, and visual effects |
| JavaScript | Interactions, language switching, and UI behavior |
| WebGL / Canvas | Animated background experience |
| GitHub Pages | Static hosting and custom domain |

## Run Locally

~~~bash
git clone https://github.com/hndzgit/namth.io.vn.git
cd namth.io.vn
python -m http.server 8000
~~~

Open <http://localhost:8000> in your browser.

## Project Structure

~~~text
namth.io.vn/
├── index.html   # Portfolio content and page structure
├── style.css    # Visual system, themes, and responsive design
├── main.js      # Interactions and visual behavior
└── CNAME        # Custom domain configuration
~~~

## Deployment

The project is a static website and can be hosted on GitHub Pages, Vercel, Netlify, or any standard web server. The included <code>CNAME</code> file maps GitHub Pages to <code>namth.id.vn</code>.
